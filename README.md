# Multitasking-Smart-Table-Lamp-s-Code
Arduino IDE (all the code that runs the camera and the screen), with the ESP32 board package and the LovyanGFX library  Python in VS Code, with pyserial, OpenCV, NumPy and EasyOCR  ESP32-S3 camera board, 2.8-inch TFT screen, breadboard, jumper wires, microSD card.
